Apex Combate para Windows

Uma plataforma. Todas as lutas.

Aplicativo para Windows 10/11 de 64 bits. Ele cria um ícone na Área de Trabalho e no Menu Iniciar e não utiliza o Opera GX.

Baixar instalador para Windows
Windows 10/1164 bits2,1 MB

Como instalar

  1. Toque ou clique em Baixar instalador para Windows.
  2. Abra `Instalar-Apex-Combate-Windows.exe` na pasta Downloads.
  3. Se o SmartScreen aparecer, escolha Mais informações e depois Executar assim mesmo.
  4. O instalador criará os atalhos e abrirá o Apex Combate em uma janela própria.

Sem Opera GX: o aplicativo chama diretamente o Microsoft Edge em modo de aplicativo. Se o Edge não estiver disponível, utiliza o Google Chrome.

Esta entrega acadêmica ainda não possui certificado comercial de assinatura de código. Por isso, o Windows pode mostrar “Editor desconhecido” na primeira execução. O aplicativo requer internet para acessar a demonstração oficial.
