# Entregas instaláveis do Apex Combate

## Android

[`Apex-Combate-Demo-v44.apk`](Apex-Combate-Demo-v44.apk)

Para instalar em vários aparelhos Android, abra `https://apex-combate-demo.onrender.com/instalar-apex-combate.html` em um computador e leia o QR Code com cada aparelho. O arquivo [`QR-Instalar-Apex-Combate-v44.png`](QR-Instalar-Apex-Combate-v44.png) também pode ser exibido ou enviado separadamente.

- aplicativo: **Apex Combate**;
- pacote: `br.com.apexcombate.app`;
- versão: `44.0-demo`;
- requisito mínimo: Android 6.0;
- tamanho aproximado: 172 KB;
- assinatura: RSA 3072 bits, exclusiva para a demonstração;
- SHA-256: consulte `Apex-Combate-Demo-v44.apk.sha256`.

### Como instalar no Android

1. Baixe ou transfira o APK para o aparelho.
2. Abra o arquivo em **Downloads** ou no gerenciador de arquivos.
3. Se o Android solicitar, autorize temporariamente a instalação proveniente desse aplicativo.
4. Toque em **Instalar**.
5. Abra **Apex Combate** com o aparelho conectado à internet.

O aviso de que o aplicativo não veio da Play Store é esperado para este pacote acadêmico. Não é necessário desativar o Google Play Protect.

## Windows

[`Instalar-Apex-Combate-Windows.exe`](Instalar-Apex-Combate-Windows.exe)

A página oficial é `https://apex-combate-demo.onrender.com/instalar-apex-combate-windows.html`.

- requisito: Windows 10 ou 11 de 64 bits;
- tamanho aproximado: 2,1 MB;
- instalação sem privilégios administrativos;
- atalhos na Área de Trabalho e no Menu Iniciar;
- execução pelo Microsoft Edge em modo de aplicativo, sem Opera GX;
- Google Chrome usado somente como alternativa quando o Edge não está disponível;
- SHA-256: consulte `Instalar-Apex-Combate-Windows.exe.sha256`.

O instalador acadêmico ainda não possui certificado comercial de assinatura de código. O SmartScreen pode mostrar **Editor desconhecido**; nesse caso, use **Mais informações → Executar assim mesmo**.

## Limites destas entregas

Os pacotes são demonstrativos e conectados ao ambiente oficial publicado no Render. Eles requerem internet e não contêm servidor, banco de dados, segredo JWT ou chave de assinatura. O APK ainda não é o futuro pacote de produção da Google Play, e o instalador Windows ainda não possui assinatura comercial de código.
