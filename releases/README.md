# APK demonstrativo do Apex Combate

## Arquivo para instalar

[`Apex-Combate-Demo-v44.apk`](Apex-Combate-Demo-v44.apk)

- aplicativo: **Apex Combate**;
- pacote: `br.com.apexcombate.app`;
- versão: `44.0-demo`;
- requisito mínimo: Android 6.0;
- tamanho aproximado: 172 KB;
- assinatura: RSA 3072 bits, exclusiva para a demonstração;
- SHA-256: consulte `Apex-Combate-Demo-v44.apk.sha256`.

## Como instalar no celular Android

1. Baixe o arquivo APK no aparelho.
2. Abra o arquivo em **Downloads** ou no gerenciador de arquivos.
3. Se o Android solicitar, autorize temporariamente a instalação de aplicativos provenientes desse navegador ou gerenciador.
4. Toque em **Instalar**.
5. Abra **Apex Combate** e mantenha o aparelho conectado à internet durante a apresentação.

O Android pode informar que o aplicativo não veio da Play Store. Isso é esperado para este pacote acadêmico de instalação direta. Não é necessário desativar o Google Play Protect.

## Limites desta entrega

Este é um APK demonstrativo conectado ao ambiente oficial publicado no Render. Ele não é o futuro pacote de produção da Google Play e não contém servidor, banco de dados, segredo JWT ou chave de assinatura.
